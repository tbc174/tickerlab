# Caderno de estudos

Aqui fica **tudo o que você aprendeu**, escrito para você reler e relembrar depois.

## Como funciona
1. **Antes** de cada passo, o Claude explica: o que é, para que serve e como fazer.
2. Você faz o passo.
3. **Depois**, o Claude escreve a nota no arquivo do assunto.
4. Você lê, corrige o que estiver estranho e acrescenta do seu jeito. Escrever com as próprias palavras é o que fixa o conteúdo.

## Formato de cada nota
Cada tópico segue o mesmo molde, para ficar fácil de achar:

- **O que é:** em uma frase
- **Para que serve:**
- **Como usar:** passo a passo ou comando
- **Exemplo:**
- **Cuidados:** erros comuns
- **Data:** quando aprendi

Dica de estudo: antes de reler uma nota, tente explicar o assunto em voz alta. Se travar, aí você sabe onde revisar.
