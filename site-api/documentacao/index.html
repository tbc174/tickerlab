Documentação · API v1

Integre sozinho, pela documentação

Endereço base: https://api.tickerlab.com.br/data/v1. Tudo é JSON. Datas em ISO (AAAA-MM-DD). Nomes de campos, parâmetros e códigos de erro em inglês.

Começar

No beta, as chaves são dadas por contrato a quem vai integrar: não há cadastro automático nem cobrança. Para pedir uma, escreva para contato@tickerlab.com.br dizendo quem é a organização e o que pretende consultar. A chave pertence à organização, e as chaves dela dividem a mesma cota.

Com a chave, a primeira chamada mostra o que ela pode pedir:

curl -H "Authorization: Bearer $TICKERLAB_CHAVE" \
  https://api.tickerlab.com.br/data/v1/catalog

O catálogo não gasta cota. Ele lista, só para a sua chave, os conjuntos, os campos, a licença e a frase de atribuição de cada fonte.

Autenticação

A chave vai só no cabeçalho: Authorization: Bearer <chave> ou X-API-Key: <chave>. Pela URL ela iria parar nos logs do servidor e da Cloudflare, então um pedido com a chave na URL (api_key, key, token…) é recusado com 400 api_key_in_url, sem repetir o valor. Chave inválida, vencida ou sem contrato dá sempre o mesmo 401 invalid_api_key: a resposta não diz qual foi o motivo.

O {cnpj} vai só com os 14 dígitos, com o dígito verificador certo. CPF nunca é aceito. assumed_return é um retorno anual que você informa (por exemplo 0.08); o custo da taxa é uma conta sobre esse número, não uma previsão de rentabilidade.

Como era na data: known_at

Toda rota de dado aceita known_at=AAAA-MM-DD. A resposta traz só o que já era público naquele dia: empresas reapresentam balanços, e a base guarda cada versão com o dia em que ficou pública. Sem o parâmetro, vale hoje. Data no futuro é recusada (400 invalid_known_at). É o que deixa um backtest honesto.

Formato da resposta

Cada valor vem num envelope com a origem:

{
  "value": …,
  "source": "cvm-hist-dfp",
  "published_at": "2025-02-27",   // o dia em que ficou público
  "observed_at": null             // quando o TickerLab o viu, se a base sabe
}

No fim da resposta, sources traz uma vez cada fonte usada, com license e attribution. As licenças abertas (ODbL da CVM, CC BY da Receita) pedem que quem redistribui cite a fonte: use a frase de attribution. Nas demonstrações, valid_until é o dia em que outra versão tomou o lugar (vazio: vale até hoje) e truncated: true avisa que o limite de linhas do plano cortou a resposta.

Lotes

Os lotes aceitam até 100 CNPJs e um known_at (e, em fundos, um assumed_return) para todos. Conta um pedido da cota por CNPJ válido e distinto; item inválido volta com status: invalid_cnpj e não conta.

curl -X POST https://api.tickerlab.com.br/data/v1/companies/batch \
  -H "Authorization: Bearer $TICKERLAB_CHAVE" -H "Content-Type: application/json" \
  -d '{"cnpjs": ["33000167000101", "33592510000154"], "known_at": "2025-04-30"}'

401invalid_api_keyChave errada, vencida ou sem contrato. A resposta não diz qual.
404not_availableO dado não existe, não pode sair pelo portão de direitos ou o CNPJ não é de uma empresa que a API serve. Os três casos respondem igual.

503service_unavailableA base está fora do ar; o pedido não conta na cota. Tente de novo.

Versões

A versão está no endereço (/data/v1). Dentro da v1 não mudamos nome de campo, de parâmetro nem código de erro; podemos acrescentar campos e rotas. Qualquer quebra vira /data/v2, com aviso antes aos titulares de chave e a v1 convivendo por um período combinado.

A licença exata e a frase de atribuição de cada resposta vêm no campo sources; esta tabela é só um resumo. Uma fonte sem licença conhecida não sai pela API. A chave pode ser suspensa se o uso quebrar a licença de uma fonte.

O que a API não entrega

  • Preços e índices da B3: não há dado aberto, só com licença da B3.
  • Dado de pessoa física: nem de sócio, nem de dívida; empresário individual e MEI não saem.
  • Tabelas cuja fonte não autoriza redistribuir.

Biblioteca Python, servidor MCP e especificação OpenAPI desta API externa ainda não existem; entram quando forem feitos. Os dados vêm das fontes oficiais e podem ter atraso ou erro da própria fonte. Nada aqui é recomendação de investimento.
